**Vocabulary**:  
**Value**: Value is composed of tints and shades. When an artist adds a tint to a color it would make the color "lighter" if used in a drawing it would give the impression that there is a light hitting that area. Same with shades, as shades make that color "darker" in value giving the impression that there is no light or little light. Value can also be used to create unity like when using the same color but with different values of the colors and/or can be used to create emphasis. 
**Space**: Space can be the "empty" part of the whole artwork or can be the space around the main focus. Artists may use space to create emphasis on their main subject or to create depth and/or reality.
**Unity**: Used to create a sense of a "whole" unity can be created when there are similar elements of art like having shapes like triangles can be big or small and using the same color throughout to create a sense of unity. Unity is created when the artist uses the same element of art and type of element (like use of straight lines) throughout their artwork.
**Balance**: When the artwork has balance it is close to symmetrical or on both sides the amount of "stuff" is even or the artist can make one side heavier in volume to create meaning. 
**Rhythm**: Artists use rhythm to create movement or flow in their artwork can use elements of art like lines, shape, and/or colors.
